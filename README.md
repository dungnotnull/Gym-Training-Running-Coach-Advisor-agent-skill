# Gym Training & Running Coach Advisor

A production-grade skill for designing safe, effective training programs grounded in exercise physiology research.

## Features

- **Progressive Overload**: Systematic training stress increase
- **Periodization Models**: Linear, Undulating (DUP), and Block periodization
- **Running Training**: VDOT-based zones with polarized 80/20 distribution
- **Recovery Monitoring**: Overtraining syndrome detection and deload protocols
- **Safety First**: Medical clearance checks and contraindication validation

## Quick Start

This skill helps design training programs for:
- Strength training (beginner to advanced)
- Running preparation (5K through marathon)
- Recovery-focused programs
- General fitness goals

## Disclaimer

**This skill provides general information only. It is not a substitute for:**
- Professional medical advice
- Certified personal trainer guidance
- In-person coaching for technique correction

**Always consult a physician before starting any new exercise program.**

## Architecture

- **Router Pattern**: Lightweight orchestrator with domain-specialized methodologies
- **Tool System**: VDOT calculator, 1RM estimator, recovery assessment
- **Validation Layer**: Program completeness checks and safety validation
- **Hooks System**: Pre/post-processing, error handling, state management

## Installation

Copy this directory to your skills folder.

## Usage

Invoke the skill and describe your training goals, experience level, and constraints.

Example: "I'm a beginner wanting to build strength with 3 days per week training"
