## [1.0.0] - 2026-08-05

### Added
- Router Pattern architecture with session management
- Three periodization models: Linear, Undulating (DUP), Block
- VDOT-based running training with polarized 80/20 distribution
- Recovery monitoring with overtraining detection
- Safety checker with medical clearance validation
- Output formatter with disclaimers and safety warnings
- Program validator with completeness checks
- Session persistence and structured logging
- Comprehensive test suite (145+ tests)

### Features
- Progressive overload methodology
- Experience-based program routing (beginner/intermediate/advanced)
- Goal classification (strength, hypertrophy, running, general)
- Constraint extraction (time, equipment, health)
- Safety flag detection (medical, injury, recovery)
- Integration with established exercise physiology research
