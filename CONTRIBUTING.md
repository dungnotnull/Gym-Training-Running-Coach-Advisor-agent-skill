# Contributing to Gym Training & Running Coach Advisor

## Code of Conduct

Be respectful, constructive, and collaborative.

## Development Setup

1. Copy this skill to your skills directory
2. Ensure Python 3.9+ is available
3. Install pytest for testing: `pip install pytest`

## Adding Methodologies

1. Create function in `methodologies/` directory
2. Add tests in `tests/test_methodologies/`
3. Follow TDD: write tests first
4. Ensure all tests pass before committing

## Testing Guidelines

- Write tests for all new functions
- Aim for >80% code coverage
- Run `pytest` before committing

## Pull Request Process

1. Create feature branch
2. Implement with tests
3. Update documentation
4. Submit PR with clear description

## Documentation Requirements

- Update README for user-facing features
- Add docstrings to all functions
- Include examples in docstrings
