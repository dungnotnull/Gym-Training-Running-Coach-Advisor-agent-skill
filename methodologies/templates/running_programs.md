# Running Training Program Templates

## Running Program Structure

### Base Building Programs (Half Marathon/Marathon)

- Duration: 12 weeks
- Focus: Aerobic base development
- Distribution: 80/20 polarized (easy vs. quality)
- Key sessions: Long runs, easy runs, tempo intervals

### Race Preparation Programs (5K/10K)

- Duration: 11 weeks
- Focus: Race-specific fitness
- Distribution: 80/20 polarized
- Key sessions: Intervals, tempo runs, goal-pace work

## Training Zones Reference

| Zone | VO2 Range | Description | Purpose |
|------|-----------|-------------|---------|
| Zone 1 | 59-74% | Easy/Recovery | Base building, recovery |
| Zone 2 | 75-82% | Marathon Pace | Endurance development |
| Zone 3 | 83-88% | Threshold/Tempo | Lactate threshold improvement |
| Zone 4 | 89-94% | Interval/VO2max | Max oxygen uptake enhancement |
| Zone 5 | 95-100% | Repetition/Speed | Economy and form improvement |

## Weekly Session Distribution

### Base Building Week
- Monday: Easy run (Zone 1)
- Wednesday: Medium long run (Zone 2)
- Friday: Rest or cross-training
- Saturday: Long run (Zone 1-2)

### Race Preparation Week
- Monday: Easy run (Zone 1)
- Wednesday: Intervals (Zone 4)
- Friday: Rest or recovery
- Saturday: Tempo run (Zone 3) or long run

## Progression Principles

1. **Progressive Overload**: Gradually increase volume/intensity
2. **Recovery**: Regular down weeks every 3-4 weeks
3. **Specificity**: Training becomes more race-specific over time
4. **Periodization**: Clear phases from base to peak to taper
